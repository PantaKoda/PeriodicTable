# Periodic Table

This project presents the chemical elements as an explorable reference. Its language distinguishes where an element occurs, whether it occurs uncombined, what it does in living systems, and how people use it.

## Language

**Element context**:
The sourced explanatory information attached to an element: natural occurrence, native occurrence, biological role, and common uses.
_Avoid_: Extra info, details

**Natural occurrence**:
The environments and materials in which an element occurs naturally, including minerals, atmosphere, oceans, and organisms, whether free or chemically bound.
_Avoid_: Found free in nature

**Native occurrence**:
Whether and where an element occurs naturally in an uncombined elemental form.
_Avoid_: Natural occurrence

**Biological role**:
An element’s established function or presence in living organisms; absence of a known role is stated explicitly.
_Avoid_: Health benefit

**Common use**:
A well-established practical, industrial, scientific, or technological application of an element or its compounds.
_Avoid_: Fun fact, possible use

**Source citation**:
A visible reference that supports an element-context claim and identifies the organization or publication responsible for it.
_Avoid_: Further reading
